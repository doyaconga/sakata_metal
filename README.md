# 高速ザンギエフのアニマルトレーニング

ザンギエフを操作して動物たちを避けながら、できるだけ長い距離を走る横スクロールアクションゲームです。

ゲームの入口は `index.html` です。画面の見た目は `styles.css`、BGM・効果音は `audio.js`、ゲーム設定とDEBUG設定の保存・読込は `config.js`、タイトルデモとランキングは `title.js`、ゲーム画面の描画は `rendering.js`、ゲーム進行・当たり判定・操作は `game.js`、ザンギエフの画像は `assets/zangief.png` に分けて保存されています。ゲームを移動・公開するときはこれらを一緒に扱ってください。ビルド作業は不要です。

## 起動方法

`index.html` をブラウザで開いてください。

音声やスマートフォンでの動作を安定させるには、ローカルWebサーバーまたは GitHub Pages などから開く方法がおすすめです。

## 操作方法

- タイトル画面の `スタート`：ゲーム開始
- タイトル画面の `ランキング`：保存された上位10件のスコアを表示
- ゲーム画面を左クリック／タップ：ジャンプ
- 空中でもう一度左クリック／タップ：二段ジャンプ
- 画面右下の「ダブルラリアット」ボタン：ダブルラリアットを発動
- ゲーム画面を右クリック：ダブルラリアットを発動
- ゲーム画面右上のポーズボタン：ゲームを一時停止
- PCの `Esc`キー：ゲームを一時停止／ポーズ中のゲームを再開
- `D`キー：当たり判定のデバッグ表示をON／OFF
- GAME OVER画面の `リトライ`：再挑戦
- GAME OVER画面の `ランキング`：タイトルと同じ上位10件を表示
- GAME OVER画面の `タイトルへ戻る`：タイトル画面へ戻る

## 現在のゲーム仕様

### タイトルとSCORE

- タイトル画面からゲーム開始とスコア一覧表示を選択できます。
- タイトル画面では、走る→ジャンプ→二段ジャンプ→ダブルラリアットで動物を吹き飛ばす→動物に衝突して爆散→逆再生で復元する流れを、短い自動デモで繰り返します。
- ジャンプ時はPCで「クリック！」、スマートフォンで「タップ！」と表示し、ダブルラリアット時はゲーム本編と同じ見た目のボタンを表示します。
- デモのジャンプ速度、重力、空中回転とダブルラリアットの回転速度・リング・嵐の演出は、本編と同じ設定に合わせています。
- デモ内の地面は固定され、歩行中の動物が右から左へ進みます。
- デモの操作表示はPCとスマートフォンで切り替わり、ゲーム本編のスコア、距離、敵、クールタイムなどには影響しません。
- 操作方法はタイトル画面のデモへ集約し、プレイ中の左上は `TOTAL SCORE` だけを表示します。DISTANCEとBESTはプレイ中には表示しません。
- `TOTAL SCORE = 走行距離 + ダブルラリアット撃破BONUS` です。
- ダブルラリアットを使わずに回避した動物からは撃破点が入りません。
- ランキングにはTOTAL SCOREだけを表示し、上位10件をブラウザの `localStorage` に保存します。1位の記録をBESTとして扱います。
- 旧バージョンの距離BEST値は削除せずブラウザ内に残しますが、現在のゲームでは表示・更新しません。

### 撃破点・コンボ

- 同じダブルラリアット中に連続して動物を吹き飛ばすとコンボになります。
- 1体目は100点、2体目は150点、3体目は200点、4体目は250点、5体目以降は1体300点です。
- 撃破時には画面中央へ `COMBO!` と獲得点が表示されます。
- ダブルラリアット終了時には、その発動で倒した数と合計BONUSを `LARIAT RESULT` として表示します。
- 鳥とコウモリの群れは、現在の内部構造に合わせて「1つの群れ＝1撃破」として数えます。
- GAME OVER画面ではTOTAL SCOREを最も大きく表示し、その下にDISTANCEとBEST COMBOだけを表示します。

### 横スクロールと二段ジャンプ

- プレイヤーは自動で走り、動物や動物の群れが右から左へ流れてきます。
- ジャンプは空中でもう一度行える二段ジャンプ方式です。
- 障害物は、通り抜けられる経路が残るように組まれた出現パターンから選ばれます。
- 距離が伸びてステージが進むと、スクロールだけでなくジャンプ、落下、動物の動きなどゲーム全体の速度感も上昇します。
- 速度には上限があります。

### 動物障害物

現在のコードには次の動物が登場します。

- ブタ：地上を進む基本的な障害物
- カメ：低く、ブタより少し遅く流れる地上障害物
- カエル：周期的に跳ねる
- イヌ：プレイヤー側へ走ったあと反転する往復移動を行う
- 鳥の群れ：横に長い低空の障害物
- コウモリの群れ：高い位置を飛び、ジャンプ時の進路を妨害する
- ヘビ：周期的に頭を持ち上げ、必要なジャンプの高さが変化する
- ウサギ：プレイヤーが近づくと反応して跳ぶ
- 牛：大きな地上障害物。歩行モーションがあり、当たり判定は見た目より小さく調整されている

鳥の群れは左側の余白を広めに取り、牛は頭・胴体・脚に分けた複数の当たり判定を組み合わせて、見た目の輪郭に近づけています。

### 盾アイテム

- ITEM CHANCEで上段の盾を選ぶと取得できます。
- 取得すると `🛡 GUARD` が表示されます。
- 盾は複数ストックでき、動物との衝突によるミスを1個につき1回だけ無効にします。
- 盾が発動した直後は、連続衝突を避けるため短時間の無敵状態になります。

### ITEM CHANCE・道中CHARGE（STEP 3）

- 一定距離ごとに通常の敵スポーンが止まり、短い安全地帯の `ITEM CHANCE` が始まります。
- 上段の `🛡 GUARD` はジャンプ、下段の `🐢 SPEED DOWN` は地上走行で取得します。
- 取得したアイテムだけが消え、選ばなかったアイテムはそのまま左へ流れて画面外へ消えます。一度のITEM CHANCEで取得できるのはどちらか一方です。
- SHIELDは複数ストックでき、HUDに `🛡 GUARD ×1` のように所持数を表示します。動物との衝突時は1個だけ消費します。
- SPEED DOWNはステージ表示や障害物の解禁状態を変えず、現在のゲーム速度だけを2段階分低下させます。その後はステージ進行ごとに通常どおり再加速します。
- `⚡ CHARGE +20%` はITEM CHANCEとは別に通常の道中へ出現します。クールダウン中だけ出現し、ジャンプして取得すると現在のクールダウンゲージを最大値の20%分回復します。
- CHARGEの回復効果は次回へ持ち越しません。すでにREADYの場合は出現しません。
- アイテム取得時は、取得内容を画面中央に短く表示してフェードアウトします。盾の取得表示は所持数を付けず `GUARD` のみ表示します。
- CHARGEでクールタイムが0になった場合は、ボタンとゲージもすぐにREADY表示へ同期します。
- 出現間隔は、0〜1500mでは600〜800m、1500〜3000mでは800〜1000m、3000m以降では1000〜1200mです。
- ITEM CHANCEの予定距離30m手前で新しい敵の出現を止め、画面内の敵がいなくなってから開始します。
- 予定距離に既存の敵が残っている場合のみ、安全のため実際の開始が数mほど後ろへずれることがあります。
- アイテム取得後30m進むと通常の敵出現を再開します。前後の安全区間は秒数ではなく距離で調整します。

### ダブルラリアット

- 発動時間は約3秒です。
- 発動した瞬間から再使用待ち時間のカウントが始まり、発動開始から約20秒後に再使用できます。
- 約3秒の発動時間もこの20秒に含まれるため、ラリアット終了後の待ち時間は約17秒です。
- ポーズ中は発動時間と再使用待ち時間のどちらも進みません。
- 画面右下のボタンに加え、PCではゲーム画面の右クリックでも発動できます。
- 発動中に接触した動物を上方へ吹き飛ばします。
- 発動中は専用の演出と騒がしいBGMに切り替わり、終了後は通常のゲームBGMへ戻ります。

### サイクロンラリアット・BONUS TIME

- 通常走行中に出現する `🌪 CYCLONE` を5個集めると、1回限りのサイクロンラリアットが自動発動します。取得済みの個数は途中で取り逃しても維持されます。
- 画面左下には暗いCYCLONEアイコンを必要数だけ表示します。取得ごとに左から点灯し、集まるほど発光の周期が速くなります。数値による取得通知は表示しません。
- 5個目の取得時は全アイコンを約0.4秒間強く点灯させ、その間はゲーム進行を停止してからカットインへ移ります。
- CYCLONEの出現間隔は初期設定で200〜700mです。平均は従来と同じ約450mに保ちつつ、運が良いプレイでは早い段階で5個揃う幅を持たせています。
- 5個目を取った時点で通常のダブルラリアットが発動中の場合は、そのラリアットが終了してからサイクロンラリアットへ自動移行します。
- 発動すると専用カットインが入り、画面内の動物が現在速度の2倍で退場します。この間は新しい敵・アイテムが出現せず、衝突判定と距離進行も停止します。
- 画面内が空になると `3 → 2 → 1 → GO!` のカウントダウンが始まり、GOと同時に6秒間のサイクロンラリアットが自動発動します。
- BONUS TIMEでは合計30体の動物が地上・低空・高空へランダムな順番で出現し、通常のラリアットと同じコンボ得点でTOTAL SCOREを稼げます。
- BONUS TIME中はジャンプと二段ジャンプを使用できます。地上・低空・高空のすべてを狙うには高さとタイミングを合わせる必要があり、取り逃した動物の得点は入りません。
- 終了時は倒した動物数と獲得BONUSを `CYCLONE RESULT` として表示し、残った専用動物を消して通常プレイへ戻ります。
- 使用後は通常のダブルラリアットへ戻り、CYCLONE所持数は0になります。再び5個集めると再使用できます。
- ゲームオーバー後の再挑戦、リスタート、タイトル復帰ではCYCLONE所持数とBONUS TIMEの状態をリセットします。
- ポーズ中はカットイン、カウントダウン、BONUS TIMEのすべてが停止します。

### ダブラリ終了予告（STEP 2）

- 残り約1秒からザンギエフがゆっくり点滅し、嵐・雨・画面揺れが徐々に弱まります。
- 残り約0.4秒になると点滅が速くなります。終了予告の警告音は使用しません。
- ダブラリ終了後は約1秒間、点滅したまま動物との当たり判定がなくなる「すり抜け無敵」状態になります。
- すり抜け無敵中は動物を吹き飛ばさず、撃破点も入らず、動物がザンギエフをそのまま通過します。
- 終了予告の開始時間と高速点滅の開始時間は `GAME_CONFIG` から調整できます。

### BGMと効果音

- タイトル画面：ほのぼのしたBGM
- ゲーム中：疾走感のあるBGM
- ダブルラリアット中：騒がしい専用BGM
- ジャンプ、開始、ボタン操作、ダメージ、GAME OVERなどの効果音
- ブラウザの自動再生制限に対応するため、最初のクリックまたはタップ後に音声が開始されます。

### GAME OVER演出

- 盾を持っておらず、通常状態で動物に衝突するとGAME OVERになります。
- GAME OVER時は操作キャラクターの画像が細かな破片に分かれ、火花とともに放射状へ爆散します。爆散後はキャラクター本体が残らず、再挑戦するまで非表示になります。
- 爆散が見えるよう、GAME OVERパネルは少し遅れて表示されます。
- 盾によるミス無効時やダブルラリアット中には爆散しません。

### スマートフォン対応

- 画面は16:9を基準に端末サイズへ合わせて表示されます。
- タイトル画面、SCORE、ジャンプ、ダブルラリアットなどはタップ操作に対応しています。
- ゲーム領域ではブラウザ既定のタッチ操作を抑え、ゲームを操作しやすくしています。
- iPhoneなどでは、HTMLファイルを直接開くよりWebサーバーや GitHub Pages から開く方が安定します。

### 当たり判定デバッグ表示

- 通常プレイ時は非表示です。
- PCの `D` キーでいつでもON／OFFを切り替えられます。
- プレイヤーの実際の当たり判定を水色、各動物障害物の実際の当たり判定を赤色の破線で表示します。
- 表示中は画面右上に `HITBOX DEBUG [D]` と表示されます。

### 複合障害物パターン（STEP 4）

- ステージ4以降に、既存動物を組み合わせた複合パターンが抽選へ加わります。
- 追加パターンは、牛＋高空コウモリ、カメ＋鳥、ブタ＋ジャンプするカエル、往復する犬＋高空コウモリです。
- すべて通常ジャンプ・二段ジャンプ・地上走行の組み合わせで突破でき、ダブルラリアットを必須にしない間隔で配置しています。
- 牛＋高空コウモリは、牛を一段ジャンプで越えて着地すればコウモリの下を通れます。不要な二段ジャンプをするとコウモリへ接触しやすい近さにしています。
- コウモリが先頭に出るパターンは使用せず、牛や犬を避けた後の空中移動を邪魔する組み合わせ専用の動物として扱います。
- 犬＋高空コウモリも、犬を一段ジャンプで越えて着地し、コウモリの下を通る構成です。犬自身の往復移動で実際の間隔が縮むことを含め、初期配置は200pxにしています。
- 高空コウモリは地上を走れば通過でき、常に最大ジャンプするのではなく着地を選ぶ役割を持ちます。
- ITEM CHANCEの準備中・実行中は通常障害物の生成が止まるため、複合パターンとアイテム選択が同時に始まることはありません。
- 蛇が頭を上下する周期は個体ごとにランダムで、初期設定では約1.1〜2.3秒です。DEBUG SETTINGSから最短・最長周期を変更できます。
- ステージ2以降には高速で走る猫が追加されます。犬との差を明確にするため、初期速度は通常スクロールの1.65倍で、DEBUG SETTINGSから倍率を変更できます。
- 猫は反応時間の短さを特徴とし、単体に加えて猫＋鳥のパターンでも出現します。画面内に別の動物が残っていても通常どおり抽選され、動物同士は接触判定を持たず互いにすり抜けます。
- 高空のコウモリが画面内に残っているときに猫が抽選された場合は、コウモリの最後尾が通過してから約0.5秒の反応時間を確保できる位置まで猫を後ろへずらします。
- ステージは動物の出現パターンを10組クリアするごとに進みます。動物を避けた場合だけでなく、ダブルラリアットで倒した場合もクリアとして数えます。複数の動物が同時に出るパターンは、すべてを避けるか倒した時点で1組分として数えます。サイクロンラリアットのボーナス用動物はステージ進行に含めません。
- 動物の登場開始は、ステージ1がブタ・カメ、ステージ2が猫・カエル・鳥、ステージ3が牛・ヘビ、ステージ4がコウモリ、ステージ5がウサギ・犬です。一度解禁された動物は、その後の全ステージで抽選対象になります。
- 抽選は、そのプレイ中に登場回数が少ない動物を含むパターンほど選ばれやすくなる「ゆるい均等化」です。完全な順番制ではないためランダム感を残しつつ、特定の動物だけ極端に出にくくなることを抑えます。
- 鳥が画面内に残っていて犬が抽選された場合も、犬の抽選自体は取り消しません。鳥を越えた後に安全に着地できる距離まで犬の出現位置を後ろへずらし、出現頻度と突破可能性を両立させます。

### 季節背景

- 背景と地面は4ステージごとに、春 → 夏 → 秋 → 冬 → 春の順でループします。
- 春は桜と花びら、夏は海・砂浜・ヤシの木、秋は紅葉と落ち葉、冬は雪原・クリスマスツリー・雪だるま・雪を表示します。
- 背景の山は、春が緑、秋が紅葉より薄い赤〜黄色、冬が輪郭つきの白です。海を見せる夏だけは山を表示しません。
- 夏のヤシは曲がった幹・垂れる葉・実が分かる形です。冬の背景オブジェクトには薄く細い青灰色の輪郭を付け、動物より奥に見えるようにしています。ツリーは緑の枝に白い雪が積もる表示です。
- 冬の地面には、実際の当たり判定と同じ高さへ専用の接地ラインを表示します。白い雪景色でも着地点を判断しやすく、季節によって操作難易度が変わらないようにしています。
- 季節の境目では、まず `STAGE 5` のようなステージ表示がフェードアウトし、その後に `SUMMER` のような季節名が表示されてフェードアウトします。
- 季節によって変わるのは見た目だけです。地面の高さ、当たり判定、動物の配置、速度などのゲーム挙動には影響しません。

### タイトル画面のDEBUG SETTINGS

- 開発版ではタイトル画面右下の `DEBUG` から、秒・メートル・点数単位で主要なバランス設定を変更できます。
- ダブラリ、終了予告、終了後無敵、回復量、コンボ得点、距離帯別ITEM CHANCE間隔、ITEM前後の敵停止距離を設定できます。
- STEP 4の確認用に、開始ステージ、最低速度、開始速度、ステージごとの速度上昇量、最高速度も変更できます。例えば開始ステージを4にすれば、最初から複合パターンの抽選対象になります。
- 開発版の左上には現在の `DEBUG STAGE / SPEED` も表示され、設定の反映を確認できます。
- `出現する動物` のチェック欄から、抽選へ含める動物を個別に選択できます。`すべて選択` と `すべて外す` にも対応し、複合パターンは構成する全動物が選択されている場合だけ出現します。
- 開発版では左上に `DEBUG ITEM NEXT`（次回予定距離）、`PREP`（敵の出現停止・退場待ち）、`ACTIVE`（ITEM CHANCE中）が追加表示されます。公開版ではDEBUG機能と一緒に消えます。
- 入力欄を変更すると自動保存されます。閉じるときとSTART直前にも再読み込みし、次のゲームへ確実に反映します。
- `適用して保存` ボタンでも手動保存できます。
- `初期値に戻す` で標準設定へ戻せます。SCOREランキングとは別の保存領域を使用します。
- 設定項目はコード内の `DEBUG_SETTING_DEFS` に1件追加すると入力欄が自動生成される構造です。
- 最終公開時は `DEBUG_BUILD` を `false` にすると、DEBUGボタンと設定画面を無効化できます。

## Codexで開発を続ける

新しいCodexタスクでこのフォルダを開き、`CODEX_PROMPT.md` の内容を最初の指示として使用してください。

ゲームは役割ごとに複数のファイルへ分かれています。変更前にGitへコミットしておくと、各改修を比較したり安全に元へ戻したりできます。
