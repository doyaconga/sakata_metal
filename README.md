# 高速ザンギエフのアニマルトレーニング

ザンギエフを操作して動物たちを避けながら、できるだけ長い距離を走る横スクロールアクションゲームです。

ゲーム本体は `index.html` だけで動作します。画像・描画・BGM・効果音などもHTML内にまとめられているため、追加の素材ファイルやビルド作業は不要です。

## 起動方法

`index.html` をブラウザで開いてください。

音声やスマートフォンでの動作を安定させるには、ローカルWebサーバーまたは GitHub Pages などから開く方法がおすすめです。

## 操作方法

- タイトル画面の `START`：ゲーム開始
- タイトル画面の `SCORE`：保存された上位10件のスコアを表示
- ゲーム画面を左クリック／タップ：ジャンプ
- 空中でもう一度左クリック／タップ：二段ジャンプ
- 画面右下の「ダブルラリアット」ボタン：ダブルラリアットを発動
- ゲーム画面を右クリック：ダブルラリアットを発動
- `D`キー：当たり判定のデバッグ表示をON／OFF
- GAME OVER画面の `RETRY`：再挑戦
- GAME OVER画面の `TITLE`：タイトル画面へ戻る

## 現在のゲーム仕様

### タイトルとSCORE

- タイトル画面からゲーム開始とスコア一覧表示を選択できます。
- `TOTAL SCORE = 走行距離 + ダブルラリアット撃破BONUS` です。
- ダブルラリアットを使わずに回避した動物からは撃破点が入りません。
- TOTAL SCOREのBEST記録と上位10件はブラウザの `localStorage` に保存されます。
- 旧バージョンの距離ランキングは削除せず、新しいTOTAL SCOREランキングとは別に保持されます。

### 撃破点・コンボ

- 同じダブルラリアット中に連続して動物を吹き飛ばすとコンボになります。
- 1体目は100点、2体目は150点、3体目は200点、4体目は250点、5体目以降は1体300点です。
- 撃破時には画面中央へ `COMBO!` と獲得点が表示されます。
- ダブルラリアット終了時には、その発動で倒した数と合計BONUSを `LARIAT RESULT` として表示します。
- 鳥とコウモリの群れは、現在の内部構造に合わせて「1つの群れ＝1撃破」として数えます。
- GAME OVER画面にはDISTANCE、DEFEATED、BEST COMBO、BONUS、TOTAL SCOREを表示します。

### 横スクロールと二段ジャンプ

- プレイヤーは自動で走り、動物や動物の群れが右から左へ流れてきます。
- ジャンプは空中でもう一度行える二段ジャンプ方式です。
- 障害物は、通り抜けられる経路が残るように組まれた出現パターンから選ばれます。
- 距離が伸びてステージが進むと、スクロールだけでなくジャンプ、落下、動物の動きなどゲーム全体の速度感も上昇します。
- 速度には上限があります。

### 動物障害物

現在のコードには次の動物が登場します。

- ブタ：地上を進む基本的な障害物
- カメ：低く、ブタより少し遅く流れる地上障害物
- カエル：周期的に跳ねる
- イヌ：プレイヤー側へ走ったあと反転する往復移動を行う
- 鳥の群れ：横に長い低空の障害物
- コウモリの群れ：高い位置を飛び、ジャンプ時の進路を妨害する
- ヘビ：周期的に頭を持ち上げ、必要なジャンプの高さが変化する
- ウサギ：プレイヤーが近づくと反応して跳ぶ
- 牛：大きな地上障害物。歩行モーションがあり、当たり判定は見た目より小さく調整されている

鳥の群れは左側の余白を広めに取り、牛は頭・胴体・脚に分けた複数の当たり判定を組み合わせて、見た目の輪郭に近づけています。

### 盾アイテム

- 約900〜1100mごと（おおむね1000mごと）に盾が出現します。
- 取得すると `🛡 GUARD` が表示されます。
- 盾は1つまで保持でき、次の衝突によるミスを1回だけ無効にします。
- 盾が発動した直後は、連続衝突を避けるため短時間の無敵状態になります。

### ダブルラリアット

- 発動時間は約3秒です。
- 使用後は約20秒のクールタイムがあります。
- 画面右下のボタンに加え、PCではゲーム画面の右クリックでも発動できます。
- 発動中に接触した動物を上方へ吹き飛ばします。
- 発動中は専用の演出と騒がしいBGMに切り替わり、終了後は通常のゲームBGMへ戻ります。

### BGMと効果音

- タイトル画面：ほのぼのしたBGM
- ゲーム中：疾走感のあるBGM
- ダブルラリアット中：騒がしい専用BGM
- ジャンプ、開始、ボタン操作、ダメージ、GAME OVERなどの効果音
- ブラウザの自動再生制限に対応するため、最初のクリックまたはタップ後に音声が開始されます。

### GAME OVER演出

- 盾を持っておらず、通常状態で動物に衝突するとGAME OVERになります。
- GAME OVER時は操作キャラクターの画像が細かな破片に分かれ、火花とともに放射状へ爆散します。爆散後はキャラクター本体が残らず、再挑戦するまで非表示になります。
- 爆散が見えるよう、GAME OVERパネルは少し遅れて表示されます。
- 盾によるミス無効時やダブルラリアット中には爆散しません。

### スマートフォン対応

- 画面は16:9を基準に端末サイズへ合わせて表示されます。
- タイトル画面、SCORE、ジャンプ、ダブルラリアットなどはタップ操作に対応しています。
- ゲーム領域ではブラウザ既定のタッチ操作を抑え、ゲームを操作しやすくしています。
- iPhoneなどでは、HTMLファイルを直接開くよりWebサーバーや GitHub Pages から開く方が安定します。

### 当たり判定デバッグ表示

- 通常プレイ時は非表示です。
- PCの `D` キーでいつでもON／OFFを切り替えられます。
- プレイヤーの実際の当たり判定を水色、各動物障害物の実際の当たり判定を赤色の破線で表示します。
- 表示中は画面右上に `HITBOX DEBUG [D]` と表示されます。

## Codexで開発を続ける

新しいCodexタスクでこのフォルダを開き、`CODEX_PROMPT.md` の内容を最初の指示として使用してください。

ゲーム本体は1枚のHTMLにまとまっています。変更前にGitへコミットしておくと、各改修を比較したり安全に元へ戻したりできます。
